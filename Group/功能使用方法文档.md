# 三国·赤壁之战 — 13 项功能具体使用方法

---

## 一、系统启动方式

### 方式一：控制台模式（默认）
```
运行 Main.java → 显示主菜单 → 输入数字选择功能
```

### 方式二：GUI 图形界面模式
```
在主菜单输入 12 → 弹出 Swing 图形界面窗口
或在 GUI 窗口中点击各标签页操作
```

### 功能 6：凯撒密码解密

**菜单编号：** 6  
**所属组员：** 组员2（计谋与密码）

**操作步骤：**
1. 在控制台输入 `6` 并回车
2. 系统自动显示 5 个预设示例
3. 系统提示 `是否自定义解密？(y/n):`
4. 输入 `y` 进入自定义解密
5. 输入密文和偏移量

**预设示例输出：**
```
🔐 凯撒密码解密示例
============================================================
示例1：khoor (偏移3) → hello
示例2：^h^e^l^l^o (偏移0) → HELLO
示例3：hello$world (偏移0) → hello world
示例4：(olleh) (偏移0) → hello
示例5：^(khoor)$(dlq)wkh$zruog (偏移3) → Hello in the world
```

**自定义解密操作示例：**
```
是否自定义解密？(y/n): y

🔐 凯撒密码解密
============================================================
特殊符号说明：
  ^x → 后面字母x大写
  $ → 空格
  (内容) → 括号内内容反转
============================================================
请输入密文：^(khoor)$(dlq)wkh$zruog
请输入偏移量：3

📝 解密结果：
  密文：^(khoor)$(dlq)wkh$zruog
  偏移：3
  明文：Hello in the world
```

**特殊符号速查表：**

| 符号 | 含义 | 示例 | 结果 |
|------|------|------|------|
| `^x` | 后面字母大写 | `^h` | `H` |
| `$` | 空格 | `hello$world` | `hello world` |
| `(内容)` | 括号内反转 | `(olleh)` | `hello` |

**预期结果：** 先展示示例，然后可自定义输入密文和偏移量进行解密。

## 三、功能速查表

| 编号 | 功能名称 | 是否需要输入 | 所属组员 | 核心算法 |
|------|----------|:----------:|:--------:|----------|
| 1 | 树形组织结构 | 否 | 组员1 | 多叉树遍历 |
| 2 | 武将排序 | 否 | 组员1 | Comparator 排序 |

## 四、常见问题

**Q：如何退出系统？**
A：在主菜单输入 `0` 并回车。

**Q：如何切换到 GUI 模式？**
A：在主菜单输入 `12` 并回车，或在 IDE 中直接运行 GUIApplication.java。

**Q：二分查找支持哪些属性名？**
A：支持中文名（领导力、武力、智力、政治、生命值）和英文名（leadership、force、intelligence、politics、hp）。

**Q：凯撒密码的偏移量可以是负数吗？**
A：可以，正数表示向后移位，负数表示向前移位。

**Q：全部展示功能需要多长时间？**
A：约 5-10 秒，每步间隔 500ms。

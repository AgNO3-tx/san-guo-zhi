# 三国·赤壁之战 - 小组成员分工文档

本文档以当前 `sunwu.*` 代码实现为准，并参考英文版小组作业 PDF 的功能板块来划分成员职责。分工原则不是按文件数量平均，而是综合考虑算法难度、交互复杂度、扩展功能数量、测试说明成本和最终整合压力。

## 一、分工原则

PDF 的主要基础板块包括：

```text
1. Forming Wu Kingdom's Hierarchy
2. Soldier's Arrangement
3. Borrowing Arrows with Straw Boats
4. Enemy Fortress Attack Simulation
5. Food Harvesting
6. Encrypted Text
7. Red Cliff on Fire
8. Engaging Cao Cao at Hua Rong Road
```

扩展功能包括 GUI、额外路径算法、动态草船、Food Harvesting I/II、增强加密、火攻最优点等。当前代码把这些内容实现为 `sunwu.app`、`sunwu.data`、`sunwu.domain`、`sunwu.service`、`sunwu.ui` 和 `sunwu` 测试包。

本次分工按以下权重均衡：

| 维度 | 说明 |
|---|---|
| 算法难度 | 图算法、矩阵连通、Dijkstra、二分查找、组合枚举等 |
| 交互复杂度 | 控制台输入、默认值、GUI 展示、样例输出 |
| 扩展功能数量 | PDF extra features 中的额外实现 |
| 代码依赖范围 | 是否依赖 `SampleData`、`domain` 类型、多个 service |
| 汇报说明成本 | 演示时是否需要讲清数据结构、流程和输出含义 |

## 二、成员职责总览

| 成员 | PDF 功能板块 | 当前代码模块 | 难度均衡说明 |
|---|---|---|---|
| 组员1 | Hierarchy + Soldier Arrangement | `HierarchyService`、`GeneralAnalyticsService`、相关 `domain` 类型 | 树结构、排序、二分查找和三人组队组合集中在同一数据模型上，算法种类多但数据范围稳定 |
| 组员2 | Straw Boats + Encrypted Text + Secure Cipher | `ArrowBorrowingService`、`CipherService` | 贪心策略与字符串解析并重，包含基础功能和加密扩展 |
| 组员3 | Fortress Attack + Weighted Terrain Path | `BattlefieldPathService`、`WeightedPathResult` | 负责 BFS 最短路径和 Dijkstra 地形耗时，是图算法核心板块 |
| 组员4 | Food Harvesting basic/I/II | `FoodHarvestService`、`FoodSimulationResult` | 覆盖基础路径过滤、队伍收益倍率和三将占营模拟，业务规则多 |
| 组员5 | Red Cliff on Fire + Hua Rong Road + GUI/Integration | `ClusterFireService`、`MazeEscapeService`、`SunWuDashboard`、`SunWuApp` | 包含矩阵、迷宫、GUI 和入口整合，单项数量多但每项边界清晰 |

## 三、详细分工

### 组员1：Hierarchy 与 Soldier Arrangement

负责功能：

```text
功能 1：权力层级树
功能 2：武将能力排序与二分查找
功能 3：按属性组队与SABC评级
```

对应 PDF：

```text
Forming Wu Kingdom's Hierarchy
Soldier's Arrangement
```

主要代码：

```text
src/main/java/sunwu/service/HierarchyService.java
src/main/java/sunwu/service/GeneralAnalyticsService.java
src/main/java/sunwu/service/HierarchyView.java
src/main/java/sunwu/domain/General.java
src/main/java/sunwu/domain/HierarchyNode.java
src/main/java/sunwu/domain/AbilityType.java
src/main/java/sunwu/domain/TeamGrade.java
src/main/java/sunwu/domain/TeamSuggestion.java
```

职责说明：

- 构建 Sun Quan、Zhou Yu、Zhang Zhao 和普通武将组成的三层树。
- 根据 `leadership + strength` 与 `intelligence + politic` 自动分配军事部或管理部。
- 实现按 Leadership、Strength、Intelligence、Politic、Hit Point 排序。
- 使用二分查找在排序后的属性列表中查找指定能力值。
- 枚举三人组合，按目标属性总分排序，并输出 S/A/B/C 评级。

难度说明：

该成员承担树、排序、二分查找和组合枚举四类数据结构/算法，虽然主要围绕武将数据，但汇报时需要解释多个算法如何共享同一套 `General` 模型，因此难度较高。

### 组员2：Straw Boats 与 Encrypted Text

负责功能：

```text
功能 4：草船借箭：原题规则
功能 5：草船借箭：动态扩展规则
功能 10：密文解密：Caesar与特殊语法
功能 11：更安全文本加密：扩展规则
```

对应 PDF：

```text
Borrowing Arrows with Straw Boats
Dynamic Arrow Borrowing
Encrypted Text
Text Converter with More Secured Encryption
```

主要代码：

```text
src/main/java/sunwu/service/ArrowBorrowingService.java
src/main/java/sunwu/service/CipherService.java
src/main/java/sunwu/domain/ArrowPlanResult.java
src/main/java/sunwu/domain/BoatConfig.java
```

职责说明：

- 根据四个方向草人数量和箭雨数组，贪心选择每轮最优朝向。
- 实现基础草船借箭规则：方向最多使用 3 次，效率为 100%、80%、40%。
- 实现动态草船规则：箭雨不要求递减，方向最多使用 2 次，效率为 100%、50%。
- 实现 Caesar 解密和 `^`、`$`、`()` 特殊语法解析。
- 实现扩展加密格式 `&num{payload}` 的加密和解密。

难度说明：

该成员同时承担数值策略和字符串处理。草船借箭需要解释贪心选择与效率衰减；密文模块需要解释移位、特殊符号转换和扩展规则，汇报维度较丰富。

### 组员3：Fortress Attack 与地形最短时间

负责功能：

```text
功能 6：攻打敌军堡垒：BFS最短路径
功能 15：敌军堡垒进阶：地形最短时间
```

对应 PDF：

```text
Enemy Fortress Attack Simulation
Enemy Fortress Attack Simulation I
Extra Algorithm Implementation
```

主要代码：

```text
src/main/java/sunwu/service/BattlefieldPathService.java
src/main/java/sunwu/service/PathResult.java
src/main/java/sunwu/service/WeightedPathResult.java
src/main/java/sunwu/domain/BattlefieldGraph.java
src/main/java/sunwu/domain/WeightedBattlefieldGraph.java
src/main/java/sunwu/domain/Edge.java
src/main/java/sunwu/domain/TerrainType.java
src/main/java/sunwu/domain/ArmyType.java
```

职责说明：

- 使用邻接表表示战场节点。
- 使用 BFS 从 Node 1 出发查找到敌军目标节点的最短路径。
- 使用父节点回溯输出所有同样长度的最短路径。
- 在带权图中根据武将兵种和地形类型计算移动时间。
- 使用 Dijkstra 算法求到目标节点的最短时间路径。

难度说明：

该成员承担图算法主线，既有无权图 BFS，又有带地形耗时的 Dijkstra。虽然菜单项数量少，但算法解释难度和报告权重较高。

负责功能：

```text
功能 8：粮草采集I：政治/智力产量最大化
功能 9：粮草采集II：三将占营模拟
```

对应 PDF：

```text
Food Harvesting
Food Harvesting I
Food Harvesting II
```

主要代码：

```text
src/main/java/sunwu/service/FoodHarvestService.java
src/main/java/sunwu/service/FoodSimulationResult.java
src/main/java/sunwu/service/GeneralAnalyticsService.java
src/main/java/sunwu/domain/General.java

```

职责说明：

- 在基础采集路径中排除用户输入的无粮节点。
- 选择政治或智力最高的三人队伍。

- 汇总模拟总成本和各武将路径。

难度说明：

该成员的重点是规则组合：路径、节点过滤、队伍评级、粮草倍率和固定模拟结果共同组成 Food Harvesting 系列。实现上比图算法轻一些，但业务规则和演示说明较多。

## 五、分工均衡总结

本分工保持每位成员都有代码相关贡献，并尽量让每个人承担一个 PDF 主板块或一组相关扩展。组员3的菜单数量少但算法难度高；组员5的功能数量多但包含大量整合和展示工作；组员2和组员4分别承担策略/字符串与粮草规则；组员1承担武将体系的多算法基础模块。整体上比单纯按文件数量分配更适合报告说明和现场演示。

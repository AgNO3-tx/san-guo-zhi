# 三国·赤壁之战 — 小组成员分工详细解说

---

## 组员1 — 武将体系（`member1_character` 包）

### 负责文件（6 个类）

| 文件名 | 行数 | 功能简述 |
|--------|------|----------|
| `Character.java` | ~80 行 | 武将实体类，定义属性体系与等级评定 |
| `TreeNode.java` | ~35 行 | 多叉树节点类 |
| `TreeStructure.java` | ~100 行 | 吴国三级树形组织结构 |
| `CharacterSorter.java` | ~80 行 | 武将多属性排序器 |
| `BinarySearch.java` | ~100 行 | 二分查找武将 |
| `TeamRecommender.java` | ~90 行 | S/A/B/C 分级组队推荐 |

### 核心功能详解

**1. 武将实体设计（Character.java）**
- 定义 5 维属性体系：领导力、武力、智力、政治、生命值
- 自动计算能力总分（五项之和），自动评定 S/A/B/C 等级
  - S 级：总分 ≥ 250
  - A 级：总分 ≥ 220
  - B 级：总分 ≥ 190
  - C 级：总分 < 190
- 自动分配部门：智力 > 武力 → 内政部，武力 > 智力 → 军事部
- 提供通用属性访问接口 `getAttribute(String attr)`

**2. 吴国三级树形组织结构（TreeStructure.java + TreeNode.java）**
- 数据结构：多叉树
- 树结构：
  ```
  👑 孙权 [君主]
    ├─ 周瑜 [军事部]
    │  ├─ 黄盖
    │  ├─ 甘宁
    │  ├─ 吕蒙
    │  ├─ 陆逊
    │  ├─ 程普
    │  ├─ 韩当
    │  ├─ 周泰
    │  ├─ 蒋钦
    │  ├─ 陈武
    │  └─ (军事部武将)
    └─ 张昭 [内政部]
       ├─ 张纮
       ├─ 顾雍
       ├─ 诸葛瑾
       ├─ 步骘
       ├─ 虞翻
       ├─ 薛综
       ├─ 陆绩
       ├─ 严峻
       ├─ 程秉
       └─ (内政部武将)
  ```
- 功能：打印组织结构图、统计各部门人数

**3. 武将多属性排序（CharacterSorter.java）**
- 支持 6 种排序维度：领导力、武力、智力、政治、生命值、总分
- 使用自定义 Comparator 实现降序排序
- 打印排名表格

**4. 二分查找（BinarySearch.java）**
- 算法：二分查找（O(log n)）
- 先按目标属性排序，再二分查找
- 支持查找所有具有相同属性值的武将（向左右扩展）

**5. 分级组队推荐（TeamRecommender.java）**
- S/A/B/C 四级分组统计
- 为政治、领导力、武力、智力各推荐 Top3 最优队伍

### 涉及的数据结构与算法
- 多叉树（树形结构）
- 排序算法（Comparator 排序）
- 二分查找（O(log n)）
- TopK 选取

## 组员2 — 计谋与密码（`member2_strategy` 包）

### 负责文件（3 个类）

| 文件名 | 行数 | 功能简述 |
|--------|------|----------|
| `GrassBoatSimulation.java` | ~140 行 | 草船借箭模拟（基础版 + 动态拓展版） |
| `CaesarCipher.java` | ~140 行 | 凯撒密码加解密（含特殊符号系统） |
| `VigenereCipher.java` | ~130 行 | 维吉尼亚密码加解密（拓展功能） |

### 核心功能详解

**1. 草船借箭模拟（GrassBoatSimulation.java）**
- 场景：船四个方向（前/左/右/后）放置草人，敌军射箭
- 基础版规则：
  - 初始草人分布：前=80, 左=60, 右=70, 后=50
  - 敌军 8 轮射箭，每轮箭数递减（100→95→90...）
  - 每轮选择最优朝向（剩余草人最多且未用完的方向）
  - 单方向最多使用 3 次
  - 效率衰减：每使用一次效率降低 20%，最低 20%
  - 计算公式：箭数 × (剩余草人 / 100) × 效率
- 动态版（拓展）规则：
  - 箭数完全随机 20~150
  - 单方向最多使用 2 次
  - 效率衰减：每使用一次效率降低 35%，最低 30%

**2. 凯撒密码解密（CaesarCipher.java）**
- 凯撒移位：每个字母按固定偏移量移位
- 特殊符号系统（创新设计）：
  - `^x` → 将 x 转为大写（如 `^h` → `H`）
  - `$` → 替换为空格（如 `hello$world` → `hello world`）
  - `(内容)` → 括号内内容反转（如 `(olleh)` → `hello`）
- 支持递归处理括号内的特殊符号
- 提供预设示例展示各种符号组合效果

**3. 维吉尼亚密码（VigenereCipher.java）— 拓展功能**
- 使用关键词进行多表替换加密
- 每个字母的偏移量由关键词对应字符决定
- 安全性分析：
  - 凯撒密码：固定偏移，26 种可能，易暴力破解
  - 维吉尼亚密码：偏移随关键词变化，破解难度指数级上升
  - 若关键词长度 ≥ 明文长度且随机，则为一次性密码本（绝对安全）

### 涉及的数据结构与算法
- 贪心算法（最优朝向选择）
- 凯撒密码（单表替换）
- 维吉尼亚密码（多表替换）
- 字符串解析与递归处理

## 组员3 — 图路径与粮草（`member3_graph` 包）

### 负责文件（4 个类）

| 文件名 | 行数 | 功能简述 |
|--------|------|----------|
| `Graph.java` | ~100 行 | 图结构（邻接表，支持有向/无向） |
| `BFSPathFinder.java` | ~100 行 | BFS 敌营进攻路径搜索 |
| `GrainCollector.java` | ~150 行 | 粮草征收路径规划 |
| `TerrainPathFinder.java` | ~180 行 | 带地形的最短时间路径（拓展） |

### 核心功能详解

**1. 图结构（Graph.java）**
- 数据结构：邻接表（`Map<Integer, List<Integer>>`）
- 支持有向边和无向边
- 提供默认地图构建方法

**2. BFS 敌营进攻路径搜索（BFSPathFinder.java）**
- 算法：BFS 广度优先搜索
- 地图：10 节点有向图
  ```
  Node 1 → 2, 3
  Node 2 → 4, 5
  Node 3 → 5, 6
  Node 4 → 7
  Node 5 → 7, 8
  Node 6 → 8, 9
  Node 7 → 10 (敌营)
  Node 8 → 10 (敌营)
  Node 9 → 10 (敌营)
  ```
- 起点 Node1，终点 Node10（敌营）
- 搜索所有可达敌营的路径（共 3 条）
- 避免环路（简单路径：不重复经过节点）

**3. 粮草征收路径规划（GrainCollector.java）**
- 算法：DFS 回溯 + 剪枝
- 地图：8 节点无向图
- 粮草分布：Node2=50, Node3=30, Node5=80, Node6=60, Node7=40
- 目标：从 Node1 出发，收集所有有粮草节点后返回起点
- 剪枝策略：当前路径已长于最佳路径时停止搜索
- 贪心部分收集：当无法全部收集时，每次去最近的有粮草节点

**4. 带地形的最短时间路径（TerrainPathFinder.java）— 拓展功能**
- 算法：Dijkstra 最短路径算法
- 4 种地形及时间系数：
  - 平地：×1.0（最快）
  - 栈道：×1.5
  - 森林：×2.0
  - 沼泽：×3.0（最慢）
- 3 种兵种及速度系数：
  - 骑兵：速度 1.5（最快）
  - 弓兵：速度 1.2
  - 步兵：速度 1.0（最慢）
- 时间计算公式：距离 / (兵种速度 / 地形系数)
- 8 节点地图，测试不同兵种组合的最短时间路径

### 涉及的数据结构与算法
- 邻接表（图存储）
- BFS 广度优先搜索
- DFS 回溯 + 剪枝
- Dijkstra 最短路径算法
- 优先队列（PriorityQueue）

## 组员4 — 战场与迷宫（`member4_battlefield` 包）

### 负责文件（2 个类）

| 文件名 | 行数 | 功能简述 |
|--------|------|----------|
| `FireAttack.java` | ~170 行 | 火烧赤壁 - 战船集群统计 + 最优火球投放点 |
| `HuarongMaze.java` | ~230 行 | 华容道迷宫追击（BFS + A*） |

### 核心功能详解

**1. 火烧赤壁（FireAttack.java）**
- 算法：DFS 连通分量
- 输入：6×7 二维矩阵（1=战船，0=空地）
  ```
  ⛵ ⛵ ·  ·  · ⛵ ⛵
  ⛵ ⛵ ·  ·  · ⛵ ·
  ·  ·  · ⛵ ⛵ ·  ·
  ·  ·  · ⛵ ⛵ ·  ·
  ⛵ ·  ·  ·  · ⛵ ⛵
  ⛵ ⛵ ·  ·  · ⛵ ⛵
  ```
- 8 连通判定（上、下、左、右、左上、右上、左下、右下）
- 统计战船集群数量（决定所需火球数）
- 最优火球投放点分析（拓展）：
  - 计算每个集群的中心点
  - 寻找使得到所有集群中心的最大曼哈顿距离最小化的位置

**2. 华容道迷宫追击（HuarongMaze.java）**
- 迷宫：9×9 网格
  - 2 = 曹操起点（🟢）
  - 3 = 出口（🚩）
  - 1 = 障碍（🧱）
  - 0 = 空地（⬛）
- BFS 搜索曹操逃亡路径
- A* 搜索算法（拓展）：
  - 启发函数：曼哈顿距离
  - 使用优先队列（PriorityQueue）按 f = g + h 排序
  - 比 BFS 更高效地找到最短路径
- 可视化迷宫打印

### 涉及的数据结构与算法
- DFS 连通分量（8 连通）
- BFS 路径搜索
- A* 启发式搜索（曼哈顿距离）
- 优先队列（PriorityQueue）
- 曼哈顿距离计算

## 组员5 — 整合与 GUI（`member5_integration` 包 + `Main.java`）

### 负责文件（3 个类）

| 文件名 | 行数 | 功能简述 |
|--------|------|----------|
| `DataInitializer.java` | ~100 行 | 数据初始化工具 |
| `GUIApplication.java` | ~400 行 | Swing 图形界面 |
| `Main.java` | ~200 行 | 主入口（控制台菜单 + 功能调度） |

### 核心功能详解

**1. 数据初始化工具（DataInitializer.java）**
- 初始化 20 位吴国武将数据（含完整属性值）
  - 军事部 10 人：周瑜、黄盖、甘宁、吕蒙、陆逊、程普、韩当、周泰、蒋钦、陈武
  - 内政部 10 人：张昭、张纮、顾雍、诸葛瑾、步骘、虞翻、薛综、陆绩、严峻、程秉
- 初始化草船借箭草人分布：前=80, 左=60, 右=70, 后=50
- 初始化战船矩阵：6×7 网格
- 初始化迷宫：9×9 网格

**2. GUI 图形界面（GUIApplication.java）**
- Swing 图形界面，窗口大小 1000×700
- 8 个标签页覆盖所有功能模块：
  1. **武将体系**：组织结构图、排序展示、二分查找、分级组队、武将列表
  2. **草船借箭**：基础模拟、动态模拟
  3. **凯撒密码**：自定义解密、示例展示
  4. **敌营进攻**：BFS 路径搜索
  5. **粮草征收**：路径规划
  6. **火烧赤壁**：集群统计、最优投放点
  7. **华容道迷宫**：BFS 搜索、A* 搜索
  8. **拓展功能**：维吉尼亚密码、地形路径、动态草船
- 控制台输出捕获：将各模块的 System.out 输出重定向到 GUI 显示区域
- 支持交互操作（输入框、按钮点击、下拉选择）

**3. 主入口（Main.java）**
- 14 个菜单选项（0-13），整合所有模块
- 控制台菜单导航
- "全部功能一键展示"：自动按顺序演示所有模块，每步间隔 500ms
- 支持启动 GUI 图形界面

### 涉及的技术
- Swing GUI 编程（JFrame、JTabbedPane、JPanel、JButton 等）
- System.out 重定向（ByteArrayOutputStream）
- 模块整合与调度
- 事件驱动编程（ActionListener）

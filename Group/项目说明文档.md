# 三国·赤壁之战 - SunWu 综合系统项目说明

本文档以当前 `codex/sunwu-battle-system` 分支中的 `sunwu.*` 代码为准，说明项目目标、架构、功能与英文版小组作业 PDF 要求之间的对应关系。

## 一、项目概述

| 项目 | 内容 |
|---|---|
| 项目名称 | Sun Wu Battle System |
| 背景主题 | Three Kingdoms: The Battle of Red Cliff |
| 编程语言 | Java |
| 运行方式 | 控制台菜单 / Swing 综合演示台 |
| 当前主入口 | `sunwu.app.SunWuApp` |
| 测试方式 | 自定义 `sunwu.SunWuTestRunner` |

项目以赤壁之战为背景，把英文 PDF 中的基础功能和扩展功能实现为控制台菜单。当前代码采用分层结构：`app` 负责入口和菜单，`data` 负责样例数据，`domain` 负责基础类型，`service` 负责算法和业务逻辑，`ui` 负责 Swing 展示，`src/test/java/sunwu` 负责测试。

### app 层

`ConsoleMenu` 定义 17 项控制台菜单和能力属性输入提示。`SunWuApp` 是主入口，负责读取用户输入、调用对应 service、处理默认值和启动 Swing 综合演示台。

### data 层

`SampleData` 集中提供系统样例数据，包括武将列表、草船方向草人数量、战场图、带地形图、火攻矩阵和华容道迷宫。

### domain 层

domain 类型负责表达系统中的基础概念，例如武将、兵种、能力类型、部门、图、边、地形、坐标、队伍建议和结果对象。service 层通过这些类型传递结构化数据，避免直接拼接复杂字符串。

### service 层

service 层实现主要算法和业务规则：

- `HierarchyService`：构建吴国权力层级树。
- `GeneralAnalyticsService`：排序、二分查找、组队组合和评级。
- `ArrowBorrowingService`：草船借箭基础规则与动态规则。
- `BattlefieldPathService`：BFS 最短路径与 Dijkstra 地形最短时间。
- `FoodHarvestService`：粮草路径、产量最大化和三将占营最小成本模拟。
- `CipherService`：Caesar 特殊语法解密和增强加密规则。
- `ClusterFireService`：战船矩阵集群统计和最优投掷点。
- `MazeEscapeService`：华容道迷宫 BFS 路径。
- `ReportFormatter`：把结构化结果格式化为控制台/GUI 文本。

### ui 层

`SunWuDashboard` 是 Swing 综合演示台。它按英文 PDF 的 Basic Features / Extra Features 建立左侧功能目录，右侧为所选板块展示说明、输入控件、运行按钮和输出区域。这样演示时可以直接展示每个作业要求是否覆盖，而不是只查看静态文本。

## 四、核心数据与算法

### 武将数据

当前样例包含 12 名吴国人物，包括 Zhang Zhao、Zhou Yu、Xu Sheng、Zhu Ge Jin、Lu Su、Tai Shi Ci、Xiao Qiao、Da Qiao、Zhou Tai、Gan Ning、Lu Meng、Huang Gai。每名武将包含：

```text
name, armyType, strength, leadership, intelligence, politic, hitPoint
```

### 层级树

`HierarchyService` 创建 Sun Quan 作为根节点，Zhou Yu 和 Zhang Zhao 作为二级节点。普通武将根据能力自动分配到军事部或管理部。

### 排序、查找与组队

`GeneralAnalyticsService` 支持按五种能力排序，并在按属性排序后的列表中执行二分查找。组队功能枚举三人组合，根据所选属性总分排序并评级。

### 草船借箭

草船借箭把四个方向的草人数量视为资源容量。基础规则中方向最多使用 3 次，动态规则中方向最多使用 2 次。每轮选择预计获得箭数最高的方向。

### 图路径

战场图使用邻接表表示。基础敌营路径使用 BFS 找到所有最短路径；地形扩展使用带权图和 Dijkstra，根据兵种与地形计算耗时。

### 粮草采集

粮草模块包含三类实现：

- 基础粮草路线：在战场图上搜索从 Node 1 出发、覆盖所有有粮节点并回到 Node 1 的简单路线；无粮节点只有在连接路线必要时才保留。
- 产量最大化：选择政治或智力最高的三人队伍，按评级应用倍率。
- 三将占营模拟：枚举 Xu Sheng、Lu Meng、Xiao Qiao 均分守军营地的路线组合，用 BFS 串联营地间最短步数，选择总成本最小的模拟。

### 加密与解密

基础加密板块使用 Caesar 解密，并处理三个特殊语法：

```text
^x  转大写
$   转空格
(text)  反转括号内文本
```

扩展加密使用 `&num{payload}` 格式，对字符做 `4 + num` 的偏移封装与还原。

### 火攻矩阵

火攻模块把 `1` 视为战船、`0` 视为空位，使用八方向连通搜索统计集群。扩展功能在每个集群内部选择最优投掷点，使火势扩散到整个集群的最大距离尽量小。

### 华容道迷宫

迷宫使用二维矩阵表示：

```text
1 = 墙
0 = 可通行
2 = 起点
3 = 出口
```

`MazeEscapeService` 使用 BFS 找到曹操从起点到出口的路径，`ReportFormatter` 用 `S`、`E`、`*` 展示路径。

## 五、运行与测试

### 运行主程序

在 IDE 中运行：

```text
sunwu.app.SunWuApp
```

或编译后运行：

```text
java -cp <compiled-output> sunwu.app.SunWuApp
```

### 运行测试

当前项目使用自定义测试运行器，不依赖 JUnit、Maven 或 Gradle。编译主代码和测试代码后运行：

```text
java -cp <compiled-output> sunwu.SunWuTestRunner
```

测试覆盖以下模块：

```text
HierarchyServiceTest
GeneralAnalyticsServiceTest
ArrowBorrowingServiceTest
BattlefieldPathServiceTest
FoodHarvestServiceTest
CipherServiceTest
ClusterFireServiceTest
MazeEscapeServiceTest
DisplayTextTest
```

测试通过时输出：

```text
All SunWu tests passed.
```

## 六、项目特点

- 使用 OOP 分层组织，入口、数据、领域模型、算法服务和展示层职责清晰。
- 覆盖树、图、队列、优先队列、组合枚举、矩阵遍历和字符串解析等数据结构与算法。
- 同时覆盖 PDF 基础功能和多个扩展功能。
- 控制台和 Swing 综合演示台两种展示方式便于演示。
- 自定义测试覆盖主要算法行为，方便在无外部依赖环境下验证。
